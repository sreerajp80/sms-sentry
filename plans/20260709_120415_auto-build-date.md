# Auto build date on the About screen

**Status:** completed

## What the issue is

The About screen shows a **Last Build Date** of `2026-06-14`, which is wrong. The
date is not computed from the build — it is a hardcoded string in the
`about_config.json` asset (`"lastBuildDate": "2026-06-14"`). Nothing updates it,
so it stays stale no matter when the app is actually built. The app is now at
v16.4 but still shows the old date.

## The plan for the fix

Make the build date automatic by injecting the real build time from Gradle into
`BuildConfig` at compile time, and have the About screen read that instead of the
JSON field. This way the value is always correct with zero manual maintenance.

Steps:

1. **`app/build.gradle.kts`** — in `defaultConfig`, add a `buildConfigField` that
   holds the current date, formatted as `yyyy-MM-dd` in local time. Something like:

   ```kotlin
   val buildDate = java.text.SimpleDateFormat("yyyy-MM-dd").format(java.util.Date())
   buildConfigField("String", "BUILD_DATE", "\"$buildDate\"")
   ```

   `buildConfig = true` is already enabled, so no other Gradle change is needed.

2. **`AboutConfig.kt`** — stop reading `lastBuildDate` from the JSON. Populate
   `AboutInfo.lastBuildDate` from `BuildConfig.BUILD_DATE` instead. Keep the
   `AboutInfo` data class shape the same (the UI still uses `lastBuildDate`), so
   only the source of the value changes.

3. **`app/src/main/assets/about_config.json`** — remove the now-unused
   `lastBuildDate` key, since the value no longer comes from here. The other three
   keys (author, ideUsed, aiUsed) stay as manual config.

## Files to be changed

- `app/build.gradle.kts` — add `BUILD_DATE` build config field.
- `app/src/main/java/in/sreerajp/sms_sentry/util/AboutConfig.kt` — read build date
  from `BuildConfig.BUILD_DATE` instead of the JSON.
- `app/src/main/assets/about_config.json` — drop the `lastBuildDate` key.

## Notes / trade-offs

- The date reflects the moment Gradle configures/builds the app, i.e. the real
  build date. It will change on each rebuild — that is the intended behavior.
- No Roborazzi screenshot test covers the About screen, so a changing date does
  not break any golden image.
- This is a date only (not a full timestamp), to match the current display.
