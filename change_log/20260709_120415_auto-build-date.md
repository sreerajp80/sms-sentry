# Auto build date on the About screen

Implements plan `plans/20260709_120415_auto-build-date.md`.

## Problem

The About screen showed a hardcoded **Last Build Date** (`2026-06-14`) read from
the `about_config.json` asset. Nothing updated it, so it went stale and no longer
matched the real build.

## Changes

- **`app/build.gradle.kts`** — added `import java.text.SimpleDateFormat` and
  `import java.util.Date`, and in `defaultConfig` added a `BUILD_DATE`
  `buildConfigField` set to the current date (`yyyy-MM-dd`, local time) computed at
  build time.
- **`app/src/main/java/in/sreerajp/sms_sentry/util/AboutConfig.kt`** — imported
  `BuildConfig` and now populates `AboutInfo.lastBuildDate` from
  `BuildConfig.BUILD_DATE` instead of the JSON asset (both the normal and the
  fallback/`catch` paths). Updated the doc comment to explain the split source.
- **`app/src/main/assets/about_config.json`** — removed the now-unused
  `lastBuildDate` key. `author`, `ideUsed`, and `aiUsed` remain manual config.

## Result

The Last Build Date is now injected at compile time and always reflects the real
build date, with no manual upkeep. Verified with
`./gradlew :app:compileDebugKotlin` (compiles cleanly).

## Note

Unrelated to this change, the app `versionName` was bumped to `16.5` in the same
edit session.
